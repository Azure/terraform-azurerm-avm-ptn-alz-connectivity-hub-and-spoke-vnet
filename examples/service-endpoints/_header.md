# Subnet Service Endpoints example

This example deploys a single hub virtual network with a user subnet that configures Azure Service Endpoints using the preferred simple `service_endpoints` set of service names.

All optional hub resources (Azure Firewall, Azure Bastion, virtual network gateways, Private DNS zones, Private DNS Resolver, DNS Resolver Policy, NAT Gateway, and the DDoS protection plan) are disabled to keep the example lightweight and inexpensive to run.
